AI-Powered Article Analysis

Link to project: https://github.com/rahulramakrishnan-3699/AI-Powered-Article-Analysis-

This project is an AI-powered tool designed to analyze articles by scraping articles from a provided URL, summarizing the key points, and predicting underlying trends of each article. 
The development process utilised AI-assisted tools, including Cursor and ChatGPT, to streamline coding and prompt engineering.

Features
- Web Scraping: Extracts article content from user-provided URLs.
- Summarization: Condenses articles into concise bullet points using Hugging Face's distilbart-cnn-12-6 model.
- Trend Prediction: Identifies trends such as funding rounds, expansion plans, or hiring activities based on the summarized content.
- Streamlit Interface: Provides an interactive web interface for users to input URLs and view analysis results.

Technologies Used
- Cursor: AI-powered code editor utilized for efficient development.
- ChatGPT: Assisted in prompt engineering and code generation.
- Python: Core programming language for implementing functionality.
- Streamlit: Framework for building the web interface.
- BeautifulSoup & Requests: Libraries used for web scraping.
- Hugging Face Transformers: Employed for text summarization.

Project Structure
- scraper.py: Scrapes article content from URLs.
- summarizer.py: Summarizes articles into bullet points.
- trend_predictor.py: Predicts trends from summaries.
- streamlit_app.py: Streamlit web interface.
- main.py: Orchestrates the entire pipeline.

Prompt-Driven Development
The project was developed using prompt engineering techniques within Cursor and ChatGPT. By iteratively crafting prompts, code components were generated and refined efficiently, demonstrating the power of AI-assisted development.
